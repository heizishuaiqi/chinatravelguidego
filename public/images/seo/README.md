# SEO默认图片

默认的SEO图片，用于没有特定图片的页面

## 技术规范
尺寸: 1200×630px, 格式: JPG, 大小: <150KB

## 命名规范
default-og.jpg, default-twitter.jpg

## 使用位置
全站默认的社交分享图片

## 图片要求
- 🎨 **高质量**: 确保图片清晰、色彩饱和
- 🔍 **SEO友好**: 文件名小写，使用连字符分隔
- 📱 **响应式**: 适合在不同设备上展示
- 🚀 **性能优化**: 控制文件大小，使用WebP格式（OG图片除外）

## 获取建议
- **免费资源**: Unsplash, Pexels, Pixabay
- **关键词**: 北京天安门, 上海外滩, 西安兵马俑 等
- **质量要求**: 高分辨率，无版权纠纷

## 注意事项
- 确保图片具有代表性，能够吸引外国游客
- 注意文化敏感性，展示中国的美好形象
- 考虑季节性，选择最佳的拍摄时间
