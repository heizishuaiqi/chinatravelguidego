# 目的地封面图片

用于目的地列表页的封面图片

## 技术规范
尺寸: 600×400px, 格式: WebP, 大小: <80KB

## 命名规范
beijing-cover.webp, shanghai-cover.webp, guangzhou-cover.webp, xian-cover.webp, chengdu-cover.webp, hangzhou-cover.webp

## 使用位置
目的地列表页/destinations使用

## 图片要求
- 🎨 **高质量**: 确保图片清晰、色彩饱和
- 🔍 **SEO友好**: 文件名小写，使用连字符分隔
- 📱 **响应式**: 适合在不同设备上展示
- 🚀 **性能优化**: 控制文件大小，使用WebP格式（OG图片除外）

## 获取建议
- **免费资源**: Unsplash, Pexels, Pixabay
- **关键词**: 北京天安门, 上海外滩, 西安兵马俑 等
- **质量要求**: 高分辨率，无版权纠纷

## 注意事项
- 确保图片具有代表性，能够吸引外国游客
- 注意文化敏感性，展示中国的美好形象
- 考虑季节性，选择最佳的拍摄时间
