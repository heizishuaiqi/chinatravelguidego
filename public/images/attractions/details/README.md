# 景点详情页图片

用于景点详情页Hero区域的背景图片

## 技术规范
尺寸: 1200×400px, 格式: WebP, 大小: <150KB

## 命名规范
forbidden-city-detail.webp, great-wall-badaling-detail.webp, temple-of-heaven-detail.webp 等23个景点

## 使用位置
景点详情页/attractions/[slug]的Hero背景

## 图片要求
- 🎨 **高质量**: 确保图片清晰、色彩饱和
- 🔍 **SEO友好**: 文件名小写，使用连字符分隔
- 📱 **响应式**: 适合在不同设备上展示
- 🚀 **性能优化**: 控制文件大小，使用WebP格式（OG图片除外）

## 获取建议
- **免费资源**: Unsplash, Pexels, Pixabay
- **关键词**: 北京天安门, 上海外滩, 西安兵马俑 等
- **质量要求**: 高分辨率，无版权纠纷

## 注意事项
- 确保图片具有代表性，能够吸引外国游客
- 注意文化敏感性，展示中国的美好形象
- 考虑季节性，选择最佳的拍摄时间
