# 食物图片目录

## 目录结构
- `dishes/covers/` - 菜品封面图 (400x300px)
- `dishes/details/` - 菜品详情图 (1200x400px)
- `dishes/og/` - OG分享图 (1200x630px)

## 图片规范
- 格式：WEBP
- 命名：{dish-slug}-{type}.WEBP
- 质量：85-90% 压缩率
