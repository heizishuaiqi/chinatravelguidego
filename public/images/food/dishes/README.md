# Dish Images

Images for individual dishes and foods.

## Directory Structure
- `covers/` - 400x300px list page thumbnails
- `details/` - 800x600px detail page main images
- `galleries/` - 800x600px additional photos (organized by dish)
- `og/` - 1200x630px social media sharing images
- `thumbnails/` - 150x150px small thumbnails
- `ingredients/` - Ingredient close-up photos

## Naming Convention
Format: `{dish-slug}-{type}.WEBP`
Example: `mapo-tofu-cover.WEBP`
