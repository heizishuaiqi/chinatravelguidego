## 🔧 **工具和工作流**

### **推荐工具**
1. **Adobe Photoshop** - 专业级批处理
2. **ImageMagick** - 命令行批处理
3. **Squoosh** - 在线压缩工具
4. **TinyPNG** - 在线压缩服务

### **批处理脚本示例**

#### **ImageMagick批处理**
```bash
# 批量调整Hero图片尺寸
for file in *.jpg; do
  convert "$file" -resize 400x300^ -gravity center -crop 400x300+0+0 +repage "${file%.jpg}-hero.webp"
done

# 批量调整Detail图片尺寸
for file in *.jpg; do
  convert "$file" -resize 1200x400^ -gravity center -crop 1200x400+0+0 +repage "${file%.jpg}-detail.webp"
done
```

#### **Photoshop动作**
1. 打开图片
2. 调整尺寸 (保持宽高比)
3. 居中裁剪
4. 调整亮度/对比度
5. 导出WebP/JPG
6. 保存到指定目录
