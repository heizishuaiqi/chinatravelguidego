# China Travel Guide - 来华旅游指南

一个专为享受中国宽松签证政策的外国游客打造的静态旅游攻略网站。

## 🌟 项目介绍

China Travel Guide 是一个基于 Next.js 15 的静态网站，旨在为外国游客提供全面的中国旅游信息。网站包含签证指南、城市攻略、景点介绍、交通信息、实用工具等模块。

## 🚀 功能特色

- **签证指南**: 各国签证政策、申请流程、免签政策详解
- **城市攻略**: 北京、上海、西安等热门城市的详细指南
- **景点信息**: 精选景点的游览指南和实用信息
- **交通指南**: 高铁、地铁、出租车等交通方式详解
- **实用信息**: 货币兑换、支付方式、应急联系等
- **语言助手**: 常用中文短语和翻译工具
- **紧急帮助**: 领事馆信息、报警电话、医疗服务

## 🛠️ 技术栈

- **前端框架**: Next.js 15 (App Router)
- **开发语言**: TypeScript
- **样式框架**: Tailwind CSS v4
- **图标库**: Lucide React
- **部署方式**: 静态导出 (Static Export)

## 📦 安装和运行

### 环境要求

- Node.js 18.17+
- npm 9.0+

### 安装步骤

1. 克隆项目
```bash
git clone <repository-url>
cd china-travel-guide
```

2. 安装依赖
```bash
npm install
```

3. 启动开发服务器
```bash
npm run dev
```

4. 在浏览器中打开 [http://localhost:3000](http://localhost:3000)

### 构建和部署

```bash
# 构建静态网站
npm run build

# 预览构建结果
npm run start
```

静态文件将生成在 `out` 目录中，可以部署到任何静态托管服务。

## 🎨 设计原则

- **简洁明了**: 信息层次清晰，避免视觉混乱
- **快速查找**: 搜索功能强大，分类导航便捷
- **移动优先**: 手机端体验优于桌面端
- **国际化**: 符合外国用户的使用习惯

## 📝 开发说明

### 添加新页面

1. 在 `src/app/` 目录下创建新的页面文件
2. 更新导航菜单 (`src/components/layout/Header.tsx`)
3. 添加相应的类型定义 (`src/types/`)
4. 创建对应的数据文件 (`src/data/`)

### 样式规范

- 使用 Tailwind CSS 进行样式编写
- 遵循响应式设计原则
- 保持组件的可重用性

### 数据管理

- 静态数据存储在 `src/data/` 目录
- 使用 TypeScript 类型确保数据一致性
- 定期更新旅游信息和政策
